# 迷你本地向量检索引擎（MiniVectorDB）
一个完全手写核心逻辑的极简本地向量检索库，不依赖Chroma、FAISS等现成向量库，实现了文本向量编码、余弦相似度Top-K检索、本地持久化的完整功能。

## 核心功能
1.  调用本地Ollama的bge-m3模型把文本转成向量
2.  手写余弦相似度计算，实现Top-K相似文本检索
3.  本地JSON持久化存储，重启程序数据不丢失
4.  纯Python实现，代码量不到100行，适合理解RAG底层向量检索的工作原理

## 运行步骤
1.  本地安装Ollama，拉取bge-m3模型：`ollama pull bge-m3`
2.  安装依赖：`pip install numpy ollama`
3.  运行测试脚本：`python test_search.py`
4.  启动交互界面：`python chat.py`

## 技术说明
- 检索逻辑：所有向量存内存中，查询时遍历所有向量计算余弦相似度，在千条数据规模下性能足够
- 局限：没有做向量索引优化，数据量超过1万条后检索速度会下降，生产环境需要替换成HNSW等索引结构
- 适用场景：个人本地知识库、小规模RAG系统的向量存储原型，适合学习向量检索底层原理
